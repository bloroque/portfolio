# Portfolio & Apprentissage React

Bienvenue sur mon projet de portfolio développé avec React, une expérience immersive où je partage mon parcours professionnel tout en explorant les méandres de la bibliothèque JavaScript la plus populaire.

## À Propos du Projet

Ce projet a pour objectif de présenter mes compétences, expériences professionnelles et projets personnels de manière dynamique. 
En utilisant React, j'ai cherché à créer une interface utilisateur réactive et conviviale, tout en approfondissant mes connaissances dans le développement web.

## Fonctionnalités

- **Présentation Interactive :** Une interface utilisateur soignée et interactive pour présenter mon parcours professionnel de manière attrayante.
- **Téléchargement de CV :** Téléchargez facilement mon CV complet pour en savoir plus sur mes compétences et expériences.
- **Projets :** Une section dédiée aux projets où je partage mes réalisations et mes contributions.

## Technologies Utilisées

- React 
- Tailwind
- Gsap
